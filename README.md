# ميزانيتي — الإصدار التأسيسي 0.2

تطبيق ويب عربي RTL، يعمل محلياً على الجهاز مع دعم تثبيت PWA عند تشغيله من HTTPS أو localhost.

## التشغيل
- فك ضغط الحزمة.
- افتح `index.html` للمعاينة الأساسية.
- لتجربة التثبيت والعمل دون اتصال شغّل المجلد عبر خادم محلي أو ارفعه إلى GitHub Pages/استضافة HTTPS.

## الموجود في هذه النسخة
- لوحة ملخص الرصيد والحركات.
- شاشة مشتريات بفئات قابلة للتحديد.
- إدخال متعدد المنتجات مع حساب فوري للكمية × السعر.
- فاتورة واحدة تسجل مصروفاً واحداً عند التأكيد فقط.
- سجل الحركات والمشتريات.
- تخصيص دخل متوقع وتوزيعه على فئات دون خصم نقدي.
- دليل منتجات وأسعار يحتفظ بسجل تغيّر السعر.
- حفظ محلي ونسخ احتياطي/استعادة JSON.
- وضع داكن وفاتح بأخضر زيتوني عميق.

## حدود مهمة قبل الاستخدام المالي الفعلي
هذه نسخة MVP تشغيلية أولى وليست الإصدار المحاسبي النهائي. التخزين الحالي localStorage وليس IndexedDB، ولا يوجد بعد دفتر قيود مزدوجة أو تدقيق محاسبي، أو دورة راتب من يوم 18 إلى يوم 17، أو التزامات متكررة/دفعات جزئية، أو خطط شراء دورية، أو حماية متقدمة من تكرار العمليات، أو اختبارات شاملة. لا تستخدمها بعد كمصدر وحيد لأموالك الحقيقية. احتفظ بنسخ احتياطية.

لا تحتوي على بيانات شخصية أو أسعار افتراضية؛ تبدأ دون رصيد أو حركات.
